# DAA-LAB-MANUAL

This repository contains Python implementations of core **Searching** and **Sorting** algorithms, created as part of the Design and Analysis of Algorithms (DAA) lab work.

## 📂 Contents

### 🔍 Searching Algorithms
| File | Algorithm | Time Complexity |
|------|-----------|------------------|
| `LinearSerch.py` | Linear Search | O(n) |
| `BinarySerch.py` | Binary Search | O(log n) |

### 🔃 Sorting Algorithms
| File | Algorithm | Time Complexity (Avg) | Space Complexity |
|------|-----------|------------------------|-------------------|
| `bubbleSort.py` | Bubble Sort | O(n²) | O(1) |
| `Selectionsort.py` | Selection Sort | O(n²) | O(1) |
| `InsertionSort.py` | Insertion Sort | O(n²) | O(1) |
| `Mergesort.py` | Merge Sort | O(n log n) | O(n) |
| `Quicksort.py` | Quick Sort | O(n log n) | O(log n) |
| `HeapSort.py` | Heap Sort | O(n log n) | O(1) |

## 🚀 How to Run

Clone the repository:
```bash
git clone https://github.com/Ruddy2310/DAA-LAB-MANUAL.git
cd DAA-LAB-MANUAL
```

Run any algorithm file directly with Python:
```bash
python BinarySerch.py
python Quicksort.py
```

## 📖 About

Each file contains a standalone implementation of the respective algorithm, along with sample driver code to demonstrate its usage. This repo is intended as a quick-reference lab manual for DAA coursework.
