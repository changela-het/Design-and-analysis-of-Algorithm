# Design and Analysis of Algorithms — Lab Programs

This repository contains Python implementations and time analysis for core Design and Analysis of Algorithms (DAA) lab experiments.

## Contents

| # | Program | File | Technique |
|---|---------|------|-----------|
| 1 | Sorting Algorithms (Bubble, Selection, Insertion, Merge, Quick) | `1_sorting_algorithms.py` | Sorting |
| 2 | Searching Algorithms (Linear, Binary — iterative & recursive) | `2_search_algorithms.py` | Searching |
| 3 | Heap Sort | `3_heap_sort.py` | Heap |
| 4 | Factorial (Iterative vs Recursive) with time analysis | `4_factorial.py` | Iteration & Recursion |
| 5 | 0/1 Knapsack Problem | `5_knapsack.py` | Dynamic Programming |
| 6 | Chain Matrix Multiplication | `6_matrix_chain_multiplication.py` | Dynamic Programming |
| 7 | Making a Change Problem (Coin Change) | `7_coin_change.py` | Dynamic Programming |

## How to Run

Each program is standalone. Run with Python 3:

```bash
python 1_sorting_algorithms.py
python 2_search_algorithms.py
python 3_heap_sort.py
python 4_factorial.py
python 5_knapsack.py
python 6_matrix_chain_multiplication.py
python 7_coin_change.py
```

## Requirements

- Python 3.x (standard library only — `time`, `random`, `sys`)
